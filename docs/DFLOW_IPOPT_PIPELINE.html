NaGen：DFlow 生成与 IPOPT 推理优化

固定架构：只优化 initial noise；Flow 参数冻结；最终结构由优化后的 initial noise 重新生成
唯一成功标准：最终校准 E_hull ≤ 0.150 eV/atom
完整推理主线（从左到右）
1

完全无条件采样

  • 采样原子数、元素序列和 initial noise
  • 此时不要求满足能量或几何约束
2

冻结 Flow 生成

  • 从 initial noise 完整积分 24 步
  • 得到未弛豫的候选晶体结构
3

IPOPT 联合优化

  • 唯一连续设计变量仍是同一个 initial noise
  • 每次试探新值都重新执行冻结 Flow
  • 能量、几何、配位和新颖性同时求解
4

最终重新生成

  • 保存优化后的 initial noise
  • 从头重新积分一次 Flow
  • 生成确定性的最终候选结构
5

一次完整弛豫

  • 仅在优化阶段 hull 达标后执行
  • UMA + FIRE/BFGS 优化晶胞与原子坐标
6

最终严格验收

  • 用弛豫后 UMA 能量重新计算 E_hull
  • 复查全部解析几何约束和新颖性
  • 全部通过才输出候选
一次 IPOPT 目标 / 约束评估内部
试探 initial noise

IPOPT 给出当前试探值；原子数和元素序列在本次求解内固定。

IPOPT 变量
冻结 Flow 重积分

使用当前试探值重新生成终点结构，梯度保留到 initial noise。

可反向传播
校准 E_hull 计算

UMA 对 Flow 终点做单点能量、力和应力计算；MP hull 参考与 MP2020 候选修正从固定组成缓存读取。

UMA 提供梯度 MP 项为常数 这里没有 FIRE/BFGS
同一个非线性问题

最小化 hull、最大化新颖性，并加入最小距离、P/Fe 配位、体积及 source prior；hull 上限作为 IPOPT 显式硬约束。

联合 NLP
梯度返回与更新

UMA 和可微约束的梯度穿过 Flow 返回 initial noise；IPOPT 产生下一次试探值。

循环至终止
优化阶段通过 保存优化后的 initial noise → 最终 Flow 重积分 → 一次完整 UMA 弛豫 → 最终同口径 E_hull 与几何验收
优化阶段未通过 明确标记 hull_constraint_violated → 不进入最终弛豫 → 更换 initial noise 继续 multistart
不变项：Flow 参数、UMA checkpoint、元素组成、MP hull 缓存与 MP2020 修正口径。 注意：IPOPT 内使用未弛豫 Flow 终点；FIRE/BFGS 只在候选通过优化阶段 hull 门槛后执行一次。
