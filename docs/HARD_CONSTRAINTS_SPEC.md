# NaGen 硬约束规范 v1（Level 0 过滤规则）

日期：2026-08-18（Phase 0）
依据：全量数据审计（`data/audit/audit_summary.json`）与优化问题定义
（`docs/OPTIMIZATION.md`）

## 1. 元素与化学体系

### 1.1 目标元素集合

- 必含：Na、P、O
- 过渡金属集合（数据驱动）：**TM = {Fe, Mn, Ti, V}**（数据中 17,774 条全部含至少一种）
- 可选：F（数据中 2,481 条/102 式，氟磷酸盐）
- 排除：C、N（数据中 1,059 条；第一阶段剔除或标记为 out-of-scope，避免模型混淆 NO3/CO3 骨架）

### 1.2 化学式约束（硬）

- 元素字母表 `E = {Na, P, O, Fe, Mn, Ti, V}`（+F 视决策）
- TM 数量 ≥ 1；P 数量 ≥ 1；O 数量 ≥ 1
- Na 允许为 0（脱钠框架，数据中 217 条），此时必须有 TM–P–O
- 电中性：`sum_i q(a_i) = 0`（氧化态猜测，数据中 77.4% 可解；不可解记录不得参与能量条件训练）

## 2. 结构硬约束（数据驱动的阈值）

### 2.1 原子间距（PBC 最小镜像）

数据实测区间（全量）：

| 键型 | 实测 min | 实测 p10 | 实测 median | 建议过滤下限 |
|---|---|---|---|
| P–O | 1.426 | 1.476 | 1.499 | 1.40 Å |
| TM–O | 1.592 | 1.837 | 1.946 | 1.55 Å（允许 V=O/Ti=O 短键） |
| Na–O | 2.108 | 2.208 | 2.271 | 2.00 Å |
| O–O | 1.364（异常） | 2.369 | 2.452 | 2.00 Å（<2.0 判异常） |
| P–P | 2.734 | 2.852 | 2.969 | 2.60 Å |
| Na–Na | 2.241 | 3.019 | 3.320 | 2.20 Å |

通用异常判据（本审计采用）：任何 pair 距离 < 0.75 ×（共价半径和）→ 异常；
数据中 199 条（215 对），抽样复核几乎全部为短 V=O/Ti=O（~1.6 Å，化学合理）。
**建议**：Level 0 硬过滤用上表键型下限，而非共价半径规则（避免误杀钒氧/钛氧短键）。

### 2.2 配位约束（沿用优化问题定义）

- P 仅允许 PO4：`CN(P, O) = 4`，且所有 O 配位（P–O cutoff 2.15 Å）
- TM 仅允许 TMO4/TMO5/TMO6：`CN(TM, O) ∈ {4, 5, 6}`（cutoff 2.4 Å）
- 数据中 128 个 CN=3 位点（94 条）、293 个 CN=7 位点（184 条）为稀有/边界案例 → 生成过滤应拒绝
- Na 配位不设硬约束（Na–O 6~8 常见），留作软约束

### 2.3 体积与密度

- 体积/原子：数据 11.0 ~ 19.7 Å³/atom（p10 12.65，p90 14.79）
- 建议过滤窗口：10.5 ~ 20.5 Å³/atom（超出即可疑）

### 2.4 原子数上限（与生成器能力耦合）

- 数据 primitive 原子数：median 91，p90 174，max 184
- MatterGen 类生成器（MP-20 先验）实际可生成范围远小于此 → **N 上限按模式冻结**：
  - CSP 固定组成：按目标组成的约简母体晶胞设定（≤ 期望原子数 × 1.5）
  - 领域微调：需显存预算与原子数分布匹配（见 Phase 1 决策）
- 超胞一致性：候选结构必须记录 primitive 还原后的 N，避免以超胞虚增容量/能量

## 3. 物性约束（沿用优化问题定义）

- 理论比容量：`Q_th = n_e F / (3.6 M) ≥ 130 mAh/g`（`n_e` 按脱嵌 Na 摩尔数、`M` 按分子量）
- 热力学稳定性：`ΔE_hull ≤ 0.150 eV/atom` —— **当前无标签**，Phase 1 需先建立 DFT 或 hull 代理（见 `DFT_CONVENTIONS.md`）；在标签建立前该约束处于"不可评估"状态，不能作为训练条件

## 4. 结构与家族约束

- 骨架家族（数据分布）：P2O7 焦磷酸（45.7%）、PO4 正磷酸（12.7%）、P4O15 等缩合磷酸（13.6%）、fluoro（14.0%）、nitro（5.5%）、meta（1.2%）、NaSICON（1.3%）
- 生成目标不得只定义 PO4；条件变量建议含骨架类型枚举
- Q 标签（P 桥氧数）可作为可算条件/评估描述符：Q0=孤立 PO4、Q1=P2O7、Q2=分支、mixed_Q、irregular_PO

## 5. Level 0 过滤流程（实现顺序）

1. 元素检查：E 子集、Na/P/O 必含、TM ≥ 1
2. 电中性（氧化态猜测）检查
3. 键型最小距离检查（§2.1 下限）
4. P/TM 配位检查（§2.2）
5. 体积/原子窗口（§2.3）
6. 原子数/超胞一致性（§2.4）
7. 结构去重 + novelty 距离（指纹库用 canonical 数据建立）
8. 物性约束（容量可算；hull 待标签）

## 6. 待冻结决策（进入 Phase 1 前）

1. 是否保留 F（建议：保留，作为独立条件；或首阶段剔除氟磷酸盐）
2. 是否剔除 C/N（建议：剔除出主训练集，保留清单备查）
3. 脱钠相（Na=0，217 条）是否作为生成目标（建议：作为"脱钠后"验证集而非主生成目标）
4. hull 标签来源与 DFT 口径（见 `DFT_CONVENTIONS.md`）
5. N 上限与生成模式（固定组成 CSP 优先）
