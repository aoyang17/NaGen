# DFT 口径与"高精度/稳定"阈值约定

日期：2026-08-18（Phase 0）
状态：**口径未定，禁止在口径冻结前发起批量 DFT**

## 1. 现状盘点（Phase 0 审计结论）

- 原始数据**没有任何 DFT 能量**：`energy_above_hull`、`energy_per_atom`、
  `formation_energy_per_atom` 全部缺失
- 唯一的能量字段 `optimized_energy_per_atom` 来自 **UMA MLFF（fairchem `omat`）**，
  不是 DFT：无泛函、无赝势、无 U 值、无磁性设置、无参考态元数据
- 35.5%（6,304 条）的 MLFF 松弛在轨迹写盘时中断，能量为未收敛值
- 因此：凸包稳定性（`ΔE_hull`）、形成能、电压/容量等热力学标签**全部不可从当前数据直接获得**

## 2. 必须确认的 DFT 口径（冻结前逐项回答）

### 2.1 电子结构设置

- 泛函：建议基线 **PBE**（与大部分 Na 正极数据库一致）；不排除 SCAN/r²SCAN 作为第二口径
- 交换关联外修正：Fe/Mn/V 等 TM 需 **+U**（旋转不变 Dudarev 形式），U 值建议引用文献常用值
  （Fe: U_eff≈4.0、Mn: U_eff≈4.0、V: U_eff≈3.1、Ti: U_eff≈3.0 eV，需与参考体系标定）
- 赝势族：建议统一 **PAW（VASP）** 或 ONCV（QE），版本记录在案
- 磁性初值：Fe³⁺/Mn³⁺/V³⁺/Ti⁴⁺ 的初始磁矩设置；是否允许自旋翻转/非共线
- 平面波截断能 / 基组：k 点密度（per Å⁻¹）、smearing、收敛阈值（能量、力、位移）

### 2.2 参考态与能量定义

- 元素/化合物参考态集合（用于形成能与凸包）
- 能量单位换算（eV/atom）与零点
- `optimized_energy_per_atom` 与 DFT 的标定方式：对同一结构分别计算 MLFF 与 DFT，
  报告 MAE/R²；**在标定前 MLFF 能量不得作为训练标签**

### 2.3 工作流设置

- 结构优化 vs 静态计算的收敛标准
- 是否做体积扫描/晶格各向异性松弛
- 超胞大小与 k 点缩放的映射规则
- 失败分类（不收敛、磁序跳变、对称性破裂）与重试策略

## 3. 建议的"高精度/稳定"阈值（草案，待 DFT 后校准）

| 指标 | 建议阈值 | 备注 |
|---|---|---|
| ΔE_hull | ≤ 0.150 eV/atom | 沿用优化问题定义；与 MP 语义一致 |
| 每原子能量离差 | 报告 | 同口径内可比 |
| 松弛收敛 | fmax ≤ 0.02 eV/Å（DFT） | 高于 MLFF 的 0.01 也可，按预算定 |
| 生成结构有效性 | 键长/配位/体积窗口见硬约束规范 | Level 0 |
| MLFF 与 DFT 能量排序相关性 | Kendall τ ≥ 0.8（目标） | 标定门 |

## 4. 分阶段接入建议

1. **Phase 1 起点**：不发起 DFT；先用 UMA/其他 MLFF 做生成后筛选，能量仅用于相对排序
2. **标定小样**：从 test split 按 family/Na 含量分层抽 30–50 个结构，做一致设置的 DFT 几何优化 + 静态，
   建立 MLFF↔DFT 映射（线性校正或直接作为代理误差评估）
3. **hull 标签**：确定参考态与凸包计算管线后，为 564 个 formula 计算组成–凸包能量表
   （可由少量 DFT 完成，公式级 564 个 → 每个做相图边界结构）
4. **Phase 3 Dflow 闭环**：DFT 参数作为版本化配置进入工作流；每次运行记录泛函/U/赝势/k 点/收敛
   阈值与数据 hash；同一排名只使用兼容口径

## 5. 当前冻结状态

- ❌ 不可做：把 MLFF 能量当 DFT 训练标签、构造凸包、直接对比 MP 的 ΔE_hull
- ✅ 可做：结构有效性过滤、配位/距离/容量（解析计算）、MLFF 相对排序与代理模型初筛、
  MLFF"可松弛性"二分类
- ⏸ 待冻结：DFT 泛函/U/赝势/参考态；"高精度稳定"的最终阈值
