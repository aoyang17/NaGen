1正式定义：候选与竞争相统一使用 UMA 能标

EhullUMA(z)=EUMA(Gθ(z))−ErefUMA(c) z：初始噪声　·　Gθ：冻结的 Flow　·　c：组成

候选端

Flow 生成结构后，由同一 UMA checkpoint、同一 omat 任务头计算每原子能量、力和应力。

参考端

MP 只提供竞争相结构；所有竞争相用同一 UMA 和同一 FIRE/BFGS 协议重算，再建立 UMA 相图。

能标一致性　不再使用 E_UMA − E_MP。约束代表“相对于 MP 竞争相结构支持集的 UMA 凸包距离”，不是严格 DFT/MP 凸包距离。

3核心难点不是凸包，而是“弛豫后能量”的梯度

真正希望约束的是完整 UMA 弛豫后的能量：

Ehull,finalUMA=EUMA(R(Gθ(z)))−ErefUMA R：完整 FIRE/BFGS 弛豫算子

为什么不直接穿过完整弛豫反传？

  • FIRE/BFGS 有步长切换、历史状态和停止判断，映射不光滑。
  • 穿过力更新通常需要 UMA 二阶导数。
  • 完全收敛后，终态对初态的局部梯度可能趋近于零。
  • 跨越不同局部能谷时，终态会发生离散跳变。

推荐处理

  • 直接优化终点 UMA 能量。
  • 同时约束最大力、应力、最短距离、配位和体积。
  • 让 Flow 直接输出接近局部极小值的结构。
  • 用弛豫后能量 ensemble 提供保守修正，而不是单独承担约束。
JF=1N∑iN∥Fi∥2Jσ=∥σ∥2 小力 + 小应力，使生成终点与完整弛豫终点更接近。

4把 Ehull 作为显式不等式，而非单纯奖励

使用未截断的原始约束：

g(z)=EUMA(Gθ(z))−ErefUMA−0.150≤0

增广拉格朗日或 IPOPT 均可。增广形式为：

ℒ=Jother+λ[g]++ρ2[g]+2
为什么更合适　你的目标是进入可行域，而不是无限降低 Ehull。进入可行域后，优化器应把自由度留给新颖性、几何合理性和源噪声先验。

保守的弛豫后代理约束

E^relaxed+κσrelaxed−ErefUMA≤0.150−δ κ：不确定性系数　·　δ：由验证集标定的安全余量

建议同时保留真实 UMA 单点约束与这个保守代理约束，避免优化器钻代理模型的空子。

6项目中的落地点与需要隔离的旧路径

正式路径可以直接复用

  • uma_hull.py：同能标凸包缓存及 fail-closed 校验。
  • uma_guidance.py：UMA 能量、力、应力 VJP。
  • multiobjective_shooting.py：源噪声优化、Ehull 约束、梯度裁剪与重积分检查。
  • relaxation_surrogate.py：弛豫后能量和几何 ensemble。

旧口径不能进入正式约束

  • calibrated_mp_hull.py：仍是 UMA 候选能量对 MP 凸包。
  • differentiable_mp_hull.py：相图面来自 MP 能量。
  • 可变组成路线若继续使用上述 MP 面，会重新引入跨能标问题。

缓存必须锁定

  • UMA checkpoint SHA-256
  • task_name="omat"
  • 竞争相结构来源与日期
  • 支持相数量完整性
  • FIRE/BFGS 参数与收敛状态
  • 每个组成的参考能与缓存哈希

一次优化求解期间参考凸包必须冻结。动态改变参考面会让目标函数非平稳，破坏梯度优化和 IPOPT 的收敛假设。

推荐的最终优化问题

minz−Novelty(Gθ(z))+η∥z−z0∥2 s.t.EUMA−ErefUMA≤0.150−δ Fmax≤Ftarget,∥σ∥≤σtarget ggeometry≤0

一句话结论：同能标 UMA 凸包可以稳定地耦合进 D-Flow；固定组成时凸包是常数偏置，UMA 力/应力提供指导梯度。最终可靠性取决于让生成终点接近弛豫极小值，并用力、应力、几何约束及保守的弛豫后能量代理共同封住优化漏洞。
