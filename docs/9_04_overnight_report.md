## 2. H1f 为什么站不住

### 2.1 论证

训练源 `wrap(target + σ·ε)`，σ = 0.5。考察任意一对原子 (i, j)：

```
源侧偏移 = wrap(d_ij + σ(ε_i − ε_j))
```

噪声项每个分量的尺度是 `σ√2 = 0.707`。环面上 wrapped normal 对均匀分布的偏离量为

```
2·exp(−2π²s²) = 2·exp(−2π²·0.5) = 2·exp(−9.87) ≈ 1.0×10⁻⁴
```

即 **0.01%**。三个坐标分量独立，联合偏离同阶。

**因此：训练源的"成对偏移"分布与 i.i.d. 均匀源在统计上不可区分。**
任何只依赖成对距离的量——包括最小原子间距、亚埃接触率——两者相同。

H1f 的前提是"模型从未见过带亚埃接触的输入"。**该前提为假：模型在训练时见过，
且出现频率与推理时完全一样。** 换掉推理入口的源不会改变任何东西。

> 注：`docs/9_03_diagnosis.md` §2.6 的推理错在一处——它正确指出"边缘均匀 ≠ 联合均匀"，
> 但随后默认联合相关性是**强**的。σ=0.5 恰好把这个相关性压到了 10⁻⁴。
> 该文的定性框架对，量级估反了。

### 2.2 那 0.33 Å 是什么

均匀点云中，期望恰好落进一对的半径：

```
N(N−1)/2 · (4/3)πr³ / V = 1   ⟹   r = (3V / 2πN(N−1))^(1/3)
```

代入 `DATA_CARD_v1` 的中位 91 原子、磷酸盐典型 ~15 Å³/atom（V ≈ 1365 Å³）：

```
r ≈ 0.43 Å   →   最小距离中位数约 0.35 Å
```

**观测到的生成中位数是 0.33 Å。**

这个吻合程度指向一个比 H1f 更严重的结论：

> **生成出来的点云，在最小距离这个统计量上与均匀随机噪声无法区分。
> 速度场基本没有在搬运点云——输出 ≈ 输入。**

### 2.3 为什么会这样（机制）

这与 2.1 是同一件事的两面。σ=0.5 把 source–target 耦合摧毁到 10⁻⁴，于是回归目标
`target − source` 的条件方差极大，flow matching 的最优解塌缩到条件均值；
而环面上按对称性该均值 ≈ 0。**模型学到的速度场在早期时间接近零，流动几乎是恒等映射。**

`hidden 192 / 5 层 ≈ 2–3M 参数` + `2,357 结构` 不足以表示近独立耦合下高度多模态的边缘速度场，
只能退化到均值。这把 H1（实现级 bug）和 H2（欠训/容量）合并成了同一个问题：
**不是某处写错了，是耦合选择让这个回归问题本身近乎不可学。**

### 3.1 指派耦合（核心改动）

思路：**源的边缘分布必须与推理一致，但配对可以自由选。**

```
1. 抽 source ~ Uniform[0,1)³   ← 与 sample.random_source 逐字相同
2. 在每个元素种类内部，解最小代价指派，使 Σ 周期位移² 最小
```

对 i.i.d. 均匀点做置换，其联合分布**精确不变**仍是均匀。
所以这是白给的：源分布分毫未动（训练/推理错配按构造消失），
而每原子位移变短、回归目标方差大幅下降，转运重新变得可学。

这就是 minibatch-OT / rectified flow 的标准做法，按结构、按种类做——
因为晶体原子是**集合**，打包数据里的下标顺序是任意的，
而现在的代码是拿 source 的第 i 个配 target 的第 i 个。

距离用 3×3×3 精确镜像搜索（对齐 `constraints.pbc_distance_matrix`），
顺带避开 H1g 那把偏松的尺子。

代价：N≈91、每种类 ~40 个，Hungarian 是 40³ ≈ 6×10⁴ 次运算，可忽略。

## 5. 关于 E_hull ≤ 0.15

直说：**现在没有任何一个 E_hull 数字可以拿来和 0.15 比。** 两个独立原因：

1. **尺子未校准** — P0.4 没跑，且 8/26 pilot 实际跑在被禁的跨能标口径上（§2.10）。
2. **被测对象不是晶体** — 0.33 Å 接触下的 22 eV/atom 是 Pauli 排斥，不是化学信息。
   对一个不构成结构的东西谈"离凸包多远"没有意义。

还有一点值得先对齐口径：**`E_hull ≤ 0.15` 是筛选阈值，不是生成器能保证的性质。**
现实的流水线是 `生成 → 弛豫 → 打分 → 保留 ≤0.15 的尾部`，
所以真正要优化的量是**单位算力下 ≤0.15 候选的产出率**。
而这个产出率现在被卡在第一步：生成器还没有产出**任何**合法晶体
（96 条引导路径中 `p_coordination_eq_4` 从未通过一次）。

所以通向 0.15 的顺序是固定的，不能跳：

```
把尺子校准 (P0.4)  →  让生成器产出真晶体 (指派耦合 + 扩数据)  →  再谈 0.15 的产出率
```
