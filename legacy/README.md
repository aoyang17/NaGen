# Legacy assets

`pre_20260908_root/` contains the root-level code, documentation, configuration,
and tests that predate the 9.10–9.11 UMA campaign.

`nonproduction_from_framework_20260910/` contains branches copied from the
independent campaign worktree but excluded from the promoted production path,
including CHGNet, occupancy-flow, training, report, benchmark, and historical
selection utilities.

These assets are retained for reference only and are not imported by the active
UMA campaign.
